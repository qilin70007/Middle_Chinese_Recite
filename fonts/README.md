# Embedded WenKai font

These WOFF2 subsets were generated from **LXGW WenKai Regular** for offline full-screen reading.

- Upstream: https://github.com/lxgw/LxgwWenKai
- License: SIL Open Font License 1.1 (see OFL.txt)
- Included Unicode: basic Latin, common punctuation, full-width forms, and CJK Unified Ideographs U+4E00–U+9FFF.

The subsets are loaded by unicode-range so Android only opens the files needed by the displayed text.
